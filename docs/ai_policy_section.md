## 〇.五、近 30 日全球政策发布 → 股市影响

这是「AI 政策深度」卡片的主问题，不是当日标题词频。实现见 `policy_impact.py`。

- **窗口**：含当日的近 30 个自然日。截止 2026-09-23 时，窗口是 2026-08-25 至 2026-09-23。截止日按**北京时间**算（`_as_of` 用 UTC+8，`POLICY_TZ_OFFSET` 可改）：CI 跑在 UTC，直接用 UTC 日期会让北京时间 0–8 点的卡片停在昨天。
- **计入什么**：台账里已核验发文日的正式发布、政策讲话（信号）和窗口内生效。8 月 19 日宣布、9 月 9 日才实施的美债回购，窗口内只记「生效」，不把发文再计一次。
- **不计入什么**：没有核实日期的快讯。当日抓取标题只用来标注「仍在定价」，不改变指数分，也不被写成新的政策发布。

### 三层结构（2026-10-28 调整）

一张卡片里同时出现三种时间关系的政策，必须分层，否则「窗口内 0 项」会把整张卡说成空白：

| 层 | 定义 | 怎么计分 | 卡片位置 |
|---|---|---|---|
| 新发文 | 发文日在窗口内 | 全额：贡献 = 方向 × 市场权重 × 类型权重 × 量级权重 | 「窗口内政策发布」 |
| 存量仍生效 | 发文早于窗口，且「发文日 + 影响期（下文 `horizon`）」**仍在窗口截止日之后**（今天还管用） | **半权**（×0.5），与新发文分开列示 | 「存量政策仍在生效」，逐条标已过天数 / 影响期至哪天 / 还剩多久 |
| 窗口内已到期 | 影响期在窗口内结束（窗口开始 ≤ 到期日 < 今天） | **不计分**，只列名字与到期日 | 「窗口内已到期」 |
| 窗口前已结束 | 影响期在窗口开始之前就走完了 | 不计分，只在 `gap_note` 里计数 | — |

- **为什么要有存量层**：政策不是发文当天就失效。2026-09-16 的美联储加息（影响期 1-8 周）、8 月 28 日的房贷新政（1-6 个月）都还在定价，但窗口一滚动到 10 月就全部「过期」——只留新发文，卡片会变成一句「没有政策」，与市场实际脱节。
- **为什么半权而不是全额**：存量给的是「方向还有效」，不是「今天有催化」。全额会让 8 月的一次讲话一直按 9 月强度计分，等于虚构了一个不存在的当日事件。半权也便于读者用「新发文 + 存量」两栏核对总分。
- **为什么已到期的要单独说、且不计分**：把过期政策继续算进指数分，是最典型的「用旧政策解释今天」。列出来是让读者知道这件事发生过、现在不再计分。
- **影响期从哪来**：台账每条政策的 `horizon` 字段（数日 / 数周 / 1-4 周 / 2-6 周 / 1-6 个月 / 6-36 个月…），未写时按 30 天处理（短假设，不延长影响）。

### 三市与主线

- **三市**：A 股、港股、美股分开给指数分和受益 / 承压板块；指数分同时给出两栏 `新发文 / 存量`，总分是两者相加。阈值：≥1.2 偏多，≥0.45 中性偏多，±0.45 内中性，≤-1.2 偏空。同一主题同向的多条只取最强一条，其余按 +0.22 记确认项，避免同日组合拳把指数分乘三倍。
- **托底 / 拉低（`driver_line`）**：每个市场再给一行「谁在托、谁在拉」，只列该市场得分绝对值 ≥ 0.2 的主线，最多各两条。这行由引擎生成（推送、页面、前端共用同一字段），不在三处各写一套。例：`托底 国内地产金融 +0.71、国内金融制度 +0.28；拉低 海外货币收紧 -0.74`。
- **主线归并**：同主题的窗口内发文与存量合成一条主线，给出方向（支撑 / 压制 / 对冲）、条数（新 N / 存量 M）和合成分，按绝对影响排序。**合成分 = 三市各自按组内规则算出的该主题得分之和**，因此「各主线合成分相加 = 三市指数分相加」（2026-10-28 实测两边都是 -1.175），可对账（先加总三市贡献再套用组内规则会破坏这个等式，不采用）。
- **已观测 vs 机制**：只有公开收盘报道才标已观测。例如 2026-09-16 美联储加息 25bp 至 3.75%-4.00% 后，道指收跌约 600 点。A 股、港股没有对应的已复核点位，就只写传导机制。
- **空窗口怎么写**：三层都没有时，三市直接给「不外推方向」，不再出现「机制推演，不外推点位」这种与「没有政策」自相矛盾的措辞。
- **诚实缺口**：`gap_note` 必须把窗口外每一条的去向交代清楚——「窗口前共 N 条：x 项影响期未走完（按半权）、y 项在窗口内到期（不计分）、z 项影响期在窗口开始前已结束（不计分），均不计为新发文」。回看早于台账的日期时，写「台账最新一条发文晚于本窗口」，不写「距今 -979 天」。

对照层（知识库检索、术语口径、舆情、传导图谱、推理链）仍排在这张卡片的后部，标题为「当日对照 · 不计入窗口发文」，不替代窗口内发文。`GET /api/policy?deep=0` 也会返回 `market_impact`。

## 〇.六、官方源头与「数据是不是新的」

台账（`_POLICY_RELEASES`）是人工核过的发文，窗口一滚动就会变空——2026-10-28 时窗口内 0 条，
最近一条发文是 2026-09-20。**只靠台账，卡片会一直说「没有新政策」，而现实里央行、美联储、
财政部每天都在发东西。** 所以数据层加了两条独立通道：

### 1. 官方源抓取（`fetch_official()`）

`OFFICIAL_SOURCES` 登记 11 个机构，字段 `key / issuer / jurisdiction / domain / entry / mode / note`：

| 模式 | 源 | 说明 |
|---|---|---|
| `html` | 美联储 `federalreserve.gov/newsevents/pressreleases.htm`、欧洲央行 `ecb.europa.eu/press/html/index.en.html`、日本央行 `boj.or.jp/en/mopo/mpmdeci/index.htm`、美国财政部 `home.treasury.gov/news/press-releases` | 抓列表页，锚文本要像发文、链接必须落在该机构官方域名下、日期取「本条锚点 → 下一条锚点」之间（否则会把下一条的日期安到这一条头上），导航 / 关于我们 / 订阅类链接丢弃 |
| `manual` | 中国政府网 `gov.cn/zhengce/`、人民银行、证监会、住房城乡建设部、金融监管总局、财政部、发改委 | **只登记入口，不臆造深层文件链接**，靠人工核对后写进台账 |

- 每个源都给状态：`ok`（抓到 N 条）/ `empty`（抓通但窗口内没有新条目）/ `error`（附异常类型与前 160 字）/
  `manual`（只登记入口）。**一个源都没抓通时，卡片如实写「尚未抓取」，不拿旧条目冒充今天。**
- 抓到的条目（`auto_releases`）只列**不计分**：`dir=0`、方向留空、`summary` 写明「影响方向待标注」。
  官方发了什么是抓取能证明的，「对市场是利好还是利空」是编辑判断，不自动编。
- 与台账去重（`dedupe_auto()`）：同一天 + 同维度或标题 4 字切片重合的，不重复列。

### 2. 当日官方源动态（`official_daily_candidates()`）

现有新闻管线里来自国务院 / 部委 / 央行 / 美联储等官方源的标题，标成**待核验发文**列出。
快讯日期不等于发文日，所以这批**不入台账、不计分**，只提示「官方源今天说了这些，核到原文再入库」。

### 3. 缓存与刷新（不再请求路径打外网）

- `policy_ledger_cache.json`：抓取结果落盘，TTL 36 小时；`load_official_cache()` 过期即返回 `None`，
  宁可显示「尚未抓取」也不拿一周前的条目冒充今天。
- 手动刷新：`python3 policy_impact.py --refresh`（加 `--write` 才写缓存；`ok=0` 时不覆盖旧缓存）。
- 定时刷新：`.github/workflows/policy-ledger.yml`，每日 01:10 UTC（09:10 北京时间）跑一次，
  写缓存 + `python3 policy_impact.py --render-index index.html` 重生成静态页政策段并提交。
- 静态页：`--render-index` 整段替换 `id="policyDeepSection"`，页面与 `/api/policy` 用同一份渲染函数。

### 4. 来源核实（`verification_report()` / `impact["official"]["entries"]`）

台账 11 条**全部**挂官方入口，并标 `source_kind`：`官方原文` / `媒体转述`。
当前 11 条的引用链接都是 `news.qq.com` / `politico.com` 等媒体转述（`官方原文 0、媒体转述 11`），
卡片照写，不把媒体转述说成官方原文。核验命令：`python3 policy_impact.py --verify`。

页面只显示一行数字：「官方入口 11 个｜抓通 x · 空 y · 失败 z · 仅入口 7｜抓取 YYYY-MM-DD HH:MM UTC｜
窗口内新发文 n 条｜台账 11 条：官方原文 0、媒体转述 11」，失败源另起一行列机构名。
不写操作提示、不写说明段落（与「说明 / 注释类文字全文隐藏」的要求一致）。

## 一、政策法规知识库外掛（RAG）

解读新政策时**先检索、再对比**，而不是让模型凭印象作答：

- **库内容**（`_POLICY_KB`，18 条，覆盖全部 8 个政策维度）：央行货币政策执行报告、
  9·24 一揽子增量政策、超长期特别国债与化债方案、大规模设备更新行动方案、「人工智能+」行动意见、
  新「国九条」与减持新规、中央金融工作会议、美联储降息与缩表、欧洲央行 / 日本央行决议、
  地产金融政策、两用物项出口管制条例、民营经济促进法、BIS 对华管制规则等。
  每条内部仍含：发文机关、时间、文件类型、关键表述、背景摘要、历史市场含义与受影响行业；
  这些字段供检索与模型判断使用，**AI 政策简报只展示日期、机关、文件类型、标题与匹配度**，
  不展示关键表述、背景摘要、历史市场含义或逐条对比文本。新增一条只需在列表里加一行，
  `dimension` 与 `_POLICY_BUCKETS` 标签对齐即可挂上当日维度。
- **检索打分**（`retrieve_policy_context()`，口径写死、可复算）：关键词命中 +2、
  当日政策维度匹配 +3、表述命中 +1.5；同分取更新的政策。内部返回 `score` / `matched` / `why`，
  但对外简报不展示逐条检索依据。
- **对比分析**（`policy_knowledge()` → `comparison`）：把当日鹰鸽取向与历史条目的取向对齐后给出
  「同向 / 反向 / 背景基准」三种解读句式，例如：历史同为收紧取向 → 合规成本与估值同时受压，
  题材与高估值先调整、龙头与高分红相对抗跌。

## 二、模拟高级分析师的推理链

四步拆解，每步都带证据（当日政策新闻 + 知识库历史政策），置信度由跨源命中数与样本量决定
（≥6 源 & ≥10 条 & ≥6 条信号 = 高；≥3 条 = 中；否则低）：

1. **宏观背景**：政策热度维度 + 鹰鸽取向 + 修饰词术语口径 + 历史政策背景
2. **行业限制**：政策净空维度 + 知识库中的制度约束（管制 / 从严 / 禁止类条款）
3. **资金流向**：政策面多空比分 + 资金偏向与回避方向 + 舆情窗口判断
4. **受益板块**：政策净多维度 + 传导链上的行业节点 + 知识库条目的受益行业

> **2026-10-28 起「AI 政策研报」栏目整栏下线**：思维导图（`policy_mindmap()`）、
> 结构化政策影响研报（`policy_research_note()`）、LSTM × Prophet 时序模型三块都不再出现在
> 推送与页面里，接口也不再返回 `mindmap` / `research` / `models`。相关函数作为离线分析工具保留，
> 需要时显式调用 `analyze_policy_deep(..., include_models=True)`。

## 三、金融术语口径（修饰词解读）

对标「国内金融巨头基于开源模型微调的金融专有大模型」的术语理解，用 `_POLICY_MODIFIERS` 术语库
（30+ 条）对政策文本中的修饰词做**经济学 + 法学双维**解读，`strength` 为 -3（收紧 / 强约束）…+3（宽松 / 强支持）：

| 修饰词 | 政策语义 | 强度 | 市场含义 |
|---|---|---|---|
| 适度宽松 | 货币政策基调转松（2024-12 中央经济工作会议后的口径） | +2.0 | 降准降息预期升温，长久期成长与高股息同时受益 |
| 稳健 / 稳健的货币政策 | 不搞强刺激、留有余地 | 0.0 / +0.5 | 不预期大水漫灌，行情依赖结构性工具与财政配合 |
| 择机（降准降息） | 落地时点不确定 | — | 市场对时点反复定价，预期本身成为波动来源 |
| 适度加力 / 更加积极 | 财政扩张 | +1.5 / +2.0 | 订单与需求可见度改善，周期与顺周期受益 |
| 从严 / 强监管 | 执法尺度与违规成本同步抬升 | -1.5 | 小市值与题材承压，龙头相对受益（法学：从严执法宣示） |
| 严禁 / 不得 | 禁止性规范 | -2.0 / -1.5 | 相关业务预期归零，替代方向受益（法学：强制性禁止规范） |
| 不搞大水漫灌 | 抑制总量宽松预期 | -1.0 | 压制流动性驱动的估值扩张 |
| 原则上 / 依法依规 / 试点 | 执行弹性与合规约束 | -0.5 / -0.5 / +0.5 | 实际影响小于字面（法学：例外许可、程序合法性） |

长词优先、短词若被长词包含则不重复计权（「适度宽松」命中后不再单算重叠短词）。
术语口径与鹰鸽取向不一致时会显式提示（例如新闻以管制表述为主、而引用的政策原文口径偏松），
不掩盖分歧。对外简报在「政策术语口径（修饰词解读）」下只显示一条加权强度与方向汇总句，不列逐项修饰词、市场含义或法律含义。

## 四、政策舆情情感打分与政策窗口期

- **统计范围**：命中政策维度关键词的舆情，**或来自官方信息源**（国务院 / 部委 / 央行 / 境外监管机构，
  官媒解读本身就是政策舆情）的条目。
- **打分口径**：正向词与负向词命中差值定极性，「坚决 / 严厉 / 罕见 / 史上最大 / 大幅」等强度词把极性加倍；
  聚合成 正向 / 中性 / 负向 计数 + 归一化情绪分（-1…1）。
- **官媒 vs 市场**：官媒 / 官方口径与市场化媒体解读分开统计，情绪差 `gap` ≥ 0.3 即判定为
  **政策窗口期 · 预期差**；同向偏正 = 情绪加速期，同向偏负 = 政策避险期，其余为观望期。
  对外只说明情绪差与统计性质，不补充历史市场解释，并固定附带「仅供参考、不作为投资依据」。

## 五、政策传导图谱

按政策维度预置传导链（`_POLICY_CHAINS`，覆盖全部 8 个维度），当日命中哪个维度就把对应的链拉出来，
并带上该维度当日的政策净向：

```
白宫 / 商务部 / 外交部（政策主体）
  └─ 半导体设备、存储芯片、军工、能源航运（受影响行业）
       上游：出口管制清单、关税税率、关键资源供给
       中游：供应链改道与转口、国产替代进度、库存与交期
       下游：终端成本、海外资本开支、风险偏好与避险资产
```

输出 `chains`（含 `nature` 结构性 / 周期性 与 `horizon` 时间尺度）、`nodes` 与 `edges`，可直接用于图形化渲染。
