## 一、为什么这样实现

用户要求“用 AI 模仿江学勤的逻辑推导”。本实现只复刻**可验证的分析结构**：

1. 公开资料把其方法概括为“结构主义历史 + 博弈论 + 心理史学隐喻”，强调参与者、激励、周期与成本账。
2. Newsweek 对 2024 年《伊朗陷阱》课程的报道具体提到：拆解特朗普、伊朗革命卫队、以色列、沙特的目标；用雅典西西里远征检验过度扩张与补给线风险。
3. 中文评论总结其核心链路为：廉价无人机 / 海峡骚扰抬高昂贵拦截成本 → 海湾能源与淡水基础设施脆弱性 → 石油美元回流与 AI / 科技资本开支承压。
4. 同一批评也指出：选择性历史类比、不可证伪假设、末世论及秘密组织叙事会损害可验证性。因此本栏目**只保留方法，不继承这些叙事**，并把证伪信号作为强制输出。

## 二、六步逻辑推导

`big_v_analysis.FRAMEWORK_STEPS` 固定六步，`AI_PROMPT` 可直接交给外部大模型复用：

| 步骤 | 问题 | 输出 |
|---|---|---|
| 01 划定棋盘 | 谁是参与者？时间尺度是选举周期、战役周期还是货币周期？ | 参与者清单与观察窗口 |
| 02 识别激励 | 每个参与者最想保住什么？选票、政权安全、盟友信用、通胀目标还是资本回报？ | 目标排序与不可让步项 |
| 03 核算约束 | 后勤、能源咽喉、债务、利率、制度制衡、盟友承载力能支撑多久？ | 资源账、财政账、政治耐心 |
| 04 升级博弈 | 低成本行动是否迫使对手付出更高防御成本？信誉困境是否把双方锁死？ | 行动—反行动树、成本交换比 |
| 05 历史类比 | 西西里远征 / 帝国过度扩张 / 长期消耗战在哪些结构变量上相似？ | 可检验假设，不当结论 |
| 06 情景证伪 | 什么信号出现后必须承认推演错了？ | 基准 / 升级 / 缓和情景与观察指标 |

| 文件 | 作用 |

```json
  "disclaimer": "AI 框架仿推演……不代表其本人观点、原话或背书。"
}
```

口径：

- **证据**：来自当次 `brief` 的真实标题，按标题规范化后跨源去重；保留最多三条源名 / 标题。
- **领域**：政治、地缘、经济各有一组中英文关键词；主题命中会把相关领域补齐。
- **置信度**：`≥4 源且 ≥6 条` 较高、`≥2 源且 ≥3 条` 中、其余低。只是样本量标签，不代表结论正确率。
- **情景权重**：由升级 / 缓和词命中与能源、军事、利率主题计算的启发式关注度，三者和为 100；**不是统计概率**。
- **诚实缺口**：任一领域没有命中只输出框架和“证据不足”，不借用别的日期的事件充当当日结论。
- **安全**：所有新闻标题在 Python 推送卡片与 JavaScript 页面中均转义；外部链接只允许 http / https。

## 四、2026-10-26 静态快照的推导示范

### 总判断

近期不是三条平行新闻，而是一条成本传导链：

> 国内政治激励 → 中东能源 / 基础设施杠杆 → 通胀与央行约束 → 财政、AI 资本开支与资产估值再定价。

基准情景是“边谈边压”。核心风险不是“某一方必然崩溃”，而是信誉困境与成本交换比把有限冲突推向更广的基础设施目标。

### 政治

- **观察**：10 月 26 日 Newsquawk 记录特朗普称是否达成协议或恢复打击已接近决定时刻；11 月 3 日美国中期选举前，Al Jazeera 报道伊朗战争已经变成汽油与食品价格的餐桌议题。
- **激励**：行政部门要展示威慑可信度；选民更在意生活成本；国会、法院和央行提供制度约束。
- **约束**：选举日历、战争授权、预算谈判、汽油价格和舆论耐心。
- **推演**：若强硬姿态的选举收益高于能源反噬，威胁会加码；若民调 / 物价恶化，谈判窗口扩大。重大动作可能被推迟到政治窗口后，而不是立即变成全面战争。
- **证伪**：两党形成稳定止损方案，且选举后没有新增兵力或打击授权。

### 地缘

- **观察**：Guardian 10 月 22 日称伊朗把海湾石油设施、海底电缆、数据中心和 AI 设施列为潜在报复目标；霍尔木兹袭船报道与卡塔尔等斡旋同时存在。
- **激励**：强势方要维护威慑信用；弱势方用低成本骚扰抬高对手防御成本；海湾国家优先保能源 / 淡水 / 金融基础设施。
- **约束**：远程投送、拦截弹药库存、海峡保险、多线联盟承诺。
- **推演**：较弱一方不必正面获胜；只要边际骚扰成本低于对手拦截成本，就能把军事优势转成财政与政治消耗。技术优势不等于升级控制权。
- **证伪**：通行量与保险费率持续回落，且有可核查的长期停火监控。

### 经济

- **观察**：Guardian 记录 10 月 22 日 Brent 约 113.4 美元；Newsquawk 10 月 26 日记录 Brent 近月回撤约 1.6%，市场等待 FOMC / ECB / BoJ；Al Jazeera 引述 AAA 称美国汽油均价超过 4.27 美元 / 加仑。
- **激励**：央行守住通胀信誉；财政保增长与融资；AI / 数据中心资本开支依赖廉价电力和低成本资金。
- **约束**：能源供给冲击不能靠降息解决；高利率、高债务与关税叠加会挤压利润率。
- **推演**：油价与运费上升 → 通胀预期黏住 → 央行难以转鸽 → 长端利率与融资成本上升 → 财政利息、AI 资本开支和高估值成长股一起承压。更可信的结果是分层再定价，而非简单“泡沫破裂”或“美元立刻崩溃”。
- **证伪**：油价持续回落、通胀预期稳定、央行明确转鸽，且 AI 融资利差与资本开支保持稳定。

### 情景树

| 情景 | 触发 | 传导 | 重点观察 |
|---|---|---|---|
| 基准 · 边谈边压 | 制裁、有限军事压力、谈判并存 | 风险溢价反复，央行保持谨慎，资产在现金流 / 防御之间轮动 | 海峡通行、斡旋、FOMC 措辞、AI 融资 |
| 升级 · 基础设施受扰 | 能源 / 淡化 / 海底电缆 / AI 设施被实际打击 | 油价与通胀预期上冲，利率与信用风险同步抬升 | 受损核实、战争险、库存补充、紧急政策 |
| 缓和 · 通行换减免 | 可核查停火 + 海峡分阶段开放 + 制裁 / 资产安排 | 风险溢价回吐，利率压力缓解，资本开支预期修复 | 停火监控、Brent / 运费回落持续性 |

## 五、方法与伦理边界

- **不是本人内容**：本栏目是 AI 的框架仿推演，不是江学勤本人言论、访谈全文、账号更新或观点转载。
- **不仿写文风**：只复用分析步骤与可计算结构，不使用第一人称或其标志性措辞。
- **剔除不可证伪叙事**：末世论、秘密组织支配世界、特定族群阴谋等不作为证据，也不据此推导。
- **历史类比有边界**：西西里远征只用于检查“过度扩张 + 补给线过长 + 低估本地抵抗”是否重现，不证明现代事件必然同结局。
- **事实与推演分离**：页面写清“观察 / 激励 / 约束 / 推演 / 证伪”；所有结论可由当日标题复查。
- **非投资建议**：情景权重不是交易信号；市场、政策和战事均可能快速变化。
