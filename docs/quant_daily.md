# AI 量化日报 · 面向 AI Agent 的日频量化执行方案

> 新增栏目：**AI 量化日报**。把「触发 → 采集 → 五维分析 → 策略信号 → 风险 → 归档」拆成 **41 个原子动作**，每个动作对应一次可调用的工具请求；A 股交易日 15:30 自动启动，16:00 前产出标准 Markdown 并归档。
>
> 页面静态快照：**2026-10-26**（`quant_daily.demo_bundle()` 渲染，示例数据包，不代表真实行情）。服务运行时 `GET /api/quant` 用当日行情 + 快讯重算。
>
> 两个模板示例：`docs/quant_daily_example_20261026.md`（示例数据包，字段全有 → 展示完整版式）、`docs/quant_daily_example_live.md`（实盘采集链路 + 离线固件报文 → 展示「实测 / 代理 / 未取得」三态与各字段口径边界）。

---

## 一、定位与边界

这个栏目要解决的是「每天收盘后自动产出一份能直接用的量化日报」，所以三件事必须写死：

1. **原子化。** 五步流程拆成 41 个动作，每个动作有编号、工具名、输入、产出、失败兜底。Agent 侧照着 `plan()['steps']` 逐个发工具调用即可，不需要再理解自然语言描述。
2. **不编数。** 任何指标当日没拿到，就写「数据暂缺」并标 ⚠️，**不用前值、估计值或同类资产顶替**。能直连的都在采集层 `quant_feeds.py` 里抓（指数行情、涨跌家数与涨跌停池、行业板块、两融、龙虎榜、10Y 国债 / 商品 / 黄金 / 汇率）；只有财报明细、一致预期、指增超额、IF·IC·IM 基差、个股截面因子（质量 / 换手 / 波动率）与舆情样本需要 Agent 工具，通过 `--input` 传 JSON 数据包，字段见第四节。
3. **可复算。** 五维打分、仓位公式、风险阈值全部是常量（`SCORING` / `RISK_RULES`），同样的输入必然得到同样的信号与仓位，事后能复盘「为什么当时给这个结论」。

信号只有三档：**看多 / 中性 / 看空**。文档、页面、推送、Markdown 里都不出现「偏强」「可能」这类模糊表述。

## 二、触发与交付

| 市场 | 触发 | 交付截止 | 说明 |
|---|---|---|---|
| A 股 | 15:30 | 16:00 | 收盘后 30 分钟内产出 |
| 港股 | 16:30 | 17:15 | 收盘（16:00）后 30 分钟 |
| 美股 | 次日 05:00 | 次日 06:00 | 夏令时收盘 04:00 后 1 小时 |

执行原则：

- 所有结论带数值、带对比：环比（前值 → 当日）或历史分位（近 10 年 / 近 5 日）。
- 信号只用看多 / 中性 / 看空三档，不写「或」「可能偏强」这类模糊表述。
- 异常数据（单指标偏离 ±20%、缺失后取前值）自动 ⚠️ 标注，并写进日报的数据体检表。
- 数据源故障自动切备用源；备用源也失败才标「数据暂缺」，其余模块照常输出。

交付物：

- `reports/YYYYMMDD_量化交易日报.md`
- 100 字以内核心摘要（置于文档顶部，同时作为接口 summary 字段）
- 异常项 ⚠️ 标注、核心信号 ✅ 标注

## 三、数据采集层（`quant_feeds.py`）

采集层与引擎分开：`quant_feeds` 只负责「把外部接口变成干净的 dict」，`quant_daily.live_bundle()` 只负责「拼装 + 记账」，`analyze()` 只负责「算」。任何一层坏掉都不影响其余两层，单点异常不会让整份日报挂掉。

### 3.1 接口与口径

| 函数 | 数据 | 主源 | 备用 / 兜底 | 口径要点 |
|---|---|---|---|---|
| `index_quotes()` | 三大指数涨跌幅、成交额、PE / PB、涨跌家数 | 东方财富 `push2/api/qt/stock/get` | `index_quotes_tencent()`（`qt.gtimg.cn`，万元 → 亿元） | 涨跌家数只累加上证 + 深证，避免把北交所 / 板块指数重复计入 |
| `index_quotes_tencent()` | 同上（无涨跌家数） | 腾讯 `qt.gtimg.cn` | — | 47 个位置字段：3=价、32=涨跌幅、37=成交额(万元)、39=PE、46=PB |
| `industry_boards()` | 行业板块涨跌幅、成交额、成交额占比、主力净流入 | 东方财富 `clist`（`fs=m:90+t:2+f:!50`） | — | 东财行业分类比申万一级更细 → 报告统一标「申万一级代理」 |
| `limit_pools(as_of)` | 涨停 / 跌停家数、板块分布、最高连板 | 东方财富 `push2ex` | — | 按 `hybk` 归板块；连板取 `lbc` 最大值 |
| `margin_balances()` | 两融余额 + 上一交易日 | 东方财富数据中心 `RPTA_RZRQ_LSHJ` | 用一个交易日字段兜底 | 元 → 亿元 |
| `billboard(as_of)` | 龙虎榜机构 / 营业部席位净买入 | 东方财富数据中心 `RPT_DAILYBILLBOARD_DETAILSNEW` | — | 同一标的多次上榜合并；只按席位名归类，**不臆断游资身份** |
| `cross_asset()` | 10Y 国债收益率、商品、黄金、汇率 | 东方财富 | 多候选代码逐个尝试 | 候选：`100.CN10Y` / `101.GC00Y→113.au0` / `100.NHCI→101.CL00Y` / `133.USDCNH→100.USDCNYC`，用哪个写哪个 |

`collect(as_of)` 并发跑全部采集（线程池），每个 job 单独 try：某个接口抛异常只让那一段变成 `{ok: false, error: ...}`，其余照常返回。`quotes` 失败会自动改打腾讯并保留 `primary_error`。

### 3.2 字段级来源记账（`provenance`）

`live_bundle()` 返回的 `bundle["provenance"]` 是逐字段的来源清单，报告里渲染成「### 采集明细」表。三种状态：

| 状态 | 标记 | 含义 |
|---|---|---|
| `live` | ✅ 实测 | 当日目标值确实取到了 |
| `proxy` | ◐ 代理 | 取到的是相近口径，**必须写清替代关系**（如价格分位代替估值分位、行业板块代替申万一级） |
| `missing` | ⚠️ 未取得 | 当日确实没拿到，写明缺什么、该找哪个接口 |

另有一个 `na`（不适用）只用于北向资金这类「制度上已停止披露」的项：它不属于「今天缺数据」，因此不打 ⚠️，改成「不适用 + 原因」。报告顶部还有 `provenance_stats`（实测 / 代理 / 未取得各几项），推送卡片与页面用一行字概括。

### 3.3 代理口径的边界

| 代理项 | 代理做法 | 什么时候不成立 |
|---|---|---|
| 价格分位 → 估值分位 | 用指数日 K 收盘价序列算近 N 年分位 | **价格分位 ≠ 估值分位**：盈利变动大时两者会背离，报告一律标「价格代理」，不冒充 PE 分位 |
| 行业板块 → 申万一级 | 东财行业分类近似申万一级 | 板块数量、成分与申万不一致，跨系统对比时按代理处理 |
| 主题强度 | 优先「成交额占比 + 涨停家数 + 连板天数」完整口径 | 涨跌停池板块名匹配不上时退化为只看成交额占比，用代理阈值（≥5% 强 / ≥3% 中），并标「（代理）」 |
| 主力资金 | 行业板块主力净流入合计 | 与「全市场主力净额」口径有差，报告标代理；有个股资金流接口时应替换 |
| 债券收益序列 | 久期 6.5 年 × 10Y 收益率变动 | 若拿到的不是收益率曲线（日均变动 > 0.3 个百分点），**直接不给债券序列**，风险平价只用其余三类资产 |
| 因子收益 | 指数收益差（规模 / 动量 / 价值 / 成长） | 质量、换手率、波动率必须用个股截面因子库，采集层给不出就不给，标「需 Agent 工具」 |
| 现金近 1 周 / 近 1 月 | 按当日货币基金收益率恒定复利推算 | 是口径假设而非实测，报告标「（代理）」 |

## 四、五步流程 × 41 个原子动作

每个动作 = 一次工具调用。字段 `工具` 是建议的动作名，Agent 侧可以换成自己数据源的同语义接口；`兜底` 说明拿不到数据时该动作应该返回什么，而不是猜一个数。

### 步骤 1：前置数据采集

**时间窗**：T 日 15:30 → 15:35（5 分钟内）　**目标**：批量拉取 T 日收盘数据并完成校验，缺项切备用源

| 编号 | 动作 | 工具 | 输入 | 产出 | 兜底 |
|---|---|---|---|---|---|
| S1-01 | 市场全景快照 | `market.snapshot` | T 日收盘 | 沪深300 / 中证500 / 中证1000 涨跌幅、全市场成交额、涨跌家数、涨跌停数 | 主源失败切腾讯日 K；成交额缺失则该列标「数据暂缺」 |
| S1-02 | 行业与风格切片 | `industry.sw1_returns` | T 日收盘 | 申万一级行业涨跌幅；大小盘、价值成长风格指数收益差 | 板块接口失败用个股涨幅中位数近似，标注代理口径 |
| S1-03 | 业绩披露清单 | `fundamental.filings` | T 日披露 | 当日财报 / 业绩预告（净利润增速、是否超预期） | 无当日披露写「今日无披露」，不补前日数据 |
| S1-04 | 估值与一致预期 | `fundamental.valuation` | T 日收盘 | 核心指数 PE / PB 近 10 年分位；行业一致预期增速环比变动 | 分位序列缺失时只给 PE / PB 原值，分位标「暂缺」 |
| S1-05 | 资金三件套 | `flow.north_margin_lhb` | T 日收盘 | 北向净流入、两融余额变动、龙虎榜净买卖 TOP 标的 | 北向停止披露 → 标注并用主力资金替代；两融缺失不推断 |
| S1-06 | 大类资产快照 | `macro.cross_asset` | T 日收盘 | 10Y 国债收益率、南华商品指数、黄金现货、美元兑人民币中间价 | 单资产缺失该行留空，不参与收益排序 |
| S1-07 | 舆情与事件 | `alt.news_sentiment` | 当日 09:00 → 15:30 | 财经热点事件、个股舆情热度排名 | 当日样本不足标「样本不足」，仅保留政策事件 |
| S1-08 | 数据校验与切源 | `pipeline.validate` | 上述 7 步结果 | 缺失项清单、异常值复核标记、实际使用的数据源 | 核心指标缺失自动切备用源；±20% 偏离打 ⚠️ 复核 |

### 步骤 2：五维量化分析

**时间窗**：15:35 → 15:50（15 分钟）　**目标**：基本面 / 资产配置 / 阿尔法 / 贝塔 / 另类，各出一张表和一句结论

| 编号 | 动作 | 工具 | 输入 | 产出 | 兜底 |
|---|---|---|---|---|---|
| S2-01 | 业绩异动分类 | `analysis.earnings_split` | S1-03 输出 | 超预期 / 符合 / 不及预期分类；净利润增速 >50%、下滑 >30% 各 TOP10 | 无披露则整节标「数据暂缺」 |
| S2-02 | 估值分位表 | `analysis.valuation_table` | S1-04 输出 | 沪深300 / 中证500 / 中证1000 的 PE、PB 与近 10 年分位、估值区间 | 缺分位只给原值 |
| S2-03 | 景气度变动 | `analysis.consensus_delta` | S1-04 输出 | 申万一级行业一致预期盈利增速环比，提升 / 下滑 TOP5 | 缺一致预期则跳过 |
| S2-04 | 基本面结论 | `analysis.conclusion` | S2-01 ~ S2-03 | 业绩驱动方向、估值修复空间、看多 / 中性 / 看空 | 证据不足按中性处理并注明 |
| S2-05 | 大类资产收益排序 | `allocation.asset_returns` | S1-06 输出 | 股票 / 债券 / 商品 / 黄金 / 现金当日收益 + 近 1 周 / 近 1 月累计 | 历史序列缺失只给当日 |
| S2-06 | 股债性价比 | `allocation.equity_bond` | S1-04 + S1-06 | 沪深300 盈利收益率 − 10Y 国债收益率、历史分位、配置偏向 | 分位序列缺失只给点差 |
| S2-07 | 风险平价仓位 | `allocation.risk_parity` | 四类资产 60 日收益序列 | 股票 / 债券 / 商品 / 现金目标仓位，与上一日对比 | 无序列则整表标「数据暂缺」，不猜权重 |
| S2-08 | 配置结论 | `analysis.conclusion` | S2-05 ~ S2-07 | 大类资产性价比排序、仓位调整方向 | — |
| S2-09 | 因子收益 | `alpha.factor_returns` | T 日全 A 截面 | 价值 / 成长 / 动量 / 波动率 / 换手率 / 质量六因子当日收益与排名 | 缺因子库则标「数据暂缺」 |
| S2-10 | 指增超额估算 | `alpha.excess_estimate` | 中证500 / 1000 成分内选股结果 | 头部指增产品当日超额、市场平均超额水平 | 无持仓数据不外推，标「样本缺失」 |
| S2-11 | 对冲成本 | `alpha.basis` | IF / IC / IM 主力合约 | 年化贴水率、对冲成本高低判断 | 合约缺失该行跳过 |
| S2-12 | 阿尔法结论 | `analysis.conclusion` | S2-09 ~ S2-11 | 当日有效因子、超额环境优劣、对冲成本变化 | — |
| S2-13 | 风格剪刀差 | `beta.style_spread` | S1-02 输出 | 大盘−小盘、价值−成长当日收益差、占优风格、近 5 日趋势 | 风格指数缺失用成分股中位数代理 |
| S2-14 | 行业强弱 | `beta.industry_rank` | S1-02 输出 | 申万一级行业按涨跌幅、成交额增速排序，强弱各 TOP5 | 成交额缺失只按涨跌幅排 |
| S2-15 | 主题资金强度 | `beta.theme_strength` | S1-07 输出 | 热点主题成交额占比、涨停家数、持续性等级（强 / 中 / 弱） | 无主题样本则整节跳过 |
| S2-16 | 贝塔结论 | `analysis.conclusion` | S2-13 ~ S2-15 | 占优风格、关注 / 规避行业、主题交易热度 | — |
| S2-17 | 舆情热度榜 | `alt.sentiment_rank` | S1-07 输出 | 全市场舆情热度 TOP10、热度变动方向、驱动事件 | 样本不足标「样本不足」 |
| S2-18 | 龙虎榜席位 | `alt.lhb_seats` | S1-05 输出 | 机构净买入 TOP5、知名游资净买入 TOP5、连续上榜标记 | 席位数据缺失只保留机构口径 |
| S2-19 | 政策事件评估 | `alt.event_impact` | S1-07 输出 | 重要政策 / 行业事件及对板块影响等级（强 / 中 / 弱） | 无当日政策事件则写明 |
| S2-20 | 另类结论 | `analysis.conclusion` | S2-17 ~ S2-19 | 情绪驱动方向、资金异动标的、事件性机会提示 | — |

### 步骤 3：明日策略信号

**时间窗**：15:50 → 15:55（5 分钟）　**目标**：把五维结论翻译成可执行的分策略指引，每条都带数值

| 编号 | 动作 | 工具 | 输入 | 产出 | 兜底 |
|---|---|---|---|---|---|
| S3-01 | 指数增强指引 | `strategy.index_enhance` | S2-12 输出 | 当日超额估算、因子暴露调整方向（加 / 减哪个因子） | 超额缺失只给因子建议 |
| S3-02 | 市场中性指引 | `strategy.market_neutral` | S2-11 输出 | 对冲成本、基差操作建议、最优对冲合约 | 基差缺失建议标「待数据」 |
| S3-03 | 贝塔轮动指引 | `strategy.beta_rotation` | S2-16 输出 | 明日推荐风格 / 行业、建议仓位、止盈止损位 | 风格信号为中性时建议不换仓 |
| S3-04 | 事件驱动池 | `strategy.event_pool` | S2-20 + S2-01 | 明日可关注的业绩 / 政策 / 舆情标的池 | 无事件则空池，不硬凑 |
| S3-05 | 总仓位中枢 | `strategy.position` | 五维信号加权 | 权益仓位中枢 0~100%，对比上一日变动 | 上一日仓位缺失则只给中枢 |

### 步骤 4：风险预警识别

**时间窗**：15:55 → 15:57（2 分钟）　**目标**：四条规则自动跑，命中即高亮，未命中也要明说

| 编号 | 动作 | 工具 | 输入 | 产出 | 兜底 |
|---|---|---|---|---|---|
| S4-01 | 极端波动 | `risk.extreme_move` | S1-01 输出 | 指数单日 |涨跌幅| ≥ 2%、成交额环比异常放大 / 萎缩 | 成交额前值缺失只判涨跌幅 |
| S4-02 | 流动性风险 | `risk.liquidity` | S1-05 输出 | 北向单日净流出 > 50 亿、两融余额大幅下降 | 北向无实时数据时该项标「不可判」 |
| S4-03 | 风格极端化 | `risk.style_extreme` | S1-02 输出 | 单一风格连续 5 日占优、行业分化度 > 历史 90% 分位 | 分位序列缺失只判连续性 |
| S4-04 | 事件风险 | `risk.event` | S1-07 输出 | 重大政策利空、外围市场大幅波动等外部冲击 | 无事件则写明「未触发」 |

### 步骤 5：日报组装归档

**时间窗**：15:57 → 16:00（3 分钟）　**目标**：按模板填充、压出 100 字摘要、按日期归档、异常项打标

| 编号 | 动作 | 工具 | 输入 | 产出 | 兜底 |
|---|---|---|---|---|---|
| S5-01 | 模板填充 | `report.render` | S2 / S3 / S4 结果 | 标准 Markdown 日报（含市场全景、五维、策略、风险四段） | 缺项写「数据暂缺 ⚠️」 |
| S5-02 | 摘要压缩 | `report.summary` | 报告全文 | 100 字以内精简结论，置于文档顶部 | 超长自动裁剪，数字优先保留 |
| S5-03 | 归档 | `report.archive` | 报告全文 | reports/YYYYMMDD_量化交易日报.md | 目录不可写时回落到 stdout 并报错 |
| S5-04 | 异常打标与日志 | `report.mark` | 数据体检结果 | ⚠️ 异常项、✅ 核心信号，以及本次实际使用的数据源 | 全程不修改原始数据 |

## 五、数据契约（`--input` JSON 数据包）

## 六、五维算法与阈值

| 维度 | 关键计算 | 阈值 / 口径 |
|---|---|---|
| 基本面 | 业绩超预期占比 ×0.5 + 估值分位（越低越好）×0.3 + 景气上修行业占比 ×0.2 | 超预期线 +50%、下滑线 -30%；PE 分位 <30% 低估 / >70% 高估 |
| 资产配置 | 股债性价比分位 ×0.6 + 商品黄金相对股票 ×0.2 + 风险平价调仓 ×0.2 | 盈利收益率 = 100/PE；债券收益用 6.5 年久期代理；风险平价目标波动 8%、单资产上限 40%、不加杠杆 |
| 阿尔法 | 指增平均超额 ×0.6 + 因子极差 ×0.4 | 对冲成本：年化贴水绝对值 <3% 判偏低、>8% 判偏高；六因子取当日多空收益 |
| 贝塔 | 风险偏好：−(大盘−小盘) ×0.35 + 行业上涨占比 ×0.45 + 主题强度 ×0.2 | 主题强度 = 成交额占比×5 + min(涨停,20)×2 + min(连板,5)×2；≥60 强、≥35 中 |
| 另类 | 舆情升温占比 ×0.35 + 事件多空比 ×0.35 + 机构净买 ×0.30 | 事件影响按提及数分档：≥4 强 / ≥2 中 |

综合分 ≥ +0.25 判看多、≤ -0.25 判看空，其余中性。数据缺失的项不参与打分，五项全缺时按中性处理并在结论里写明原因。

## 七、风险规则与仓位公式

| 规则 | 触发条件 | 等级 |
|---|---|---|
| 市场极端波动 | 指数单日涨跌幅绝对值 ≥ 2%；成交额环比变动 ≥ 30% | 高 |
| 流动性风险 | 北向单日净流出 > 50 亿；两融余额环比下降 > 1% | 高 |
| 风格极端化 | 单一风格连续 5 日占优；行业分化度 > 历史 90% 分位 | 高 |
| 事件风险 | 重大政策利空；外围市场单日跌幅 ≥ 3% | 中 |
| 数据完整度 | 任一数据类当日未取得 | 中 |

仓位（权益中枢，0~100%）：

```text
综合分 = Σ 维度得分 × 权重（基本面 .22 / 配置 .22 / 阿尔法 .20 / 贝塔 .20 / 另类 .16）
权益中枢 = clamp(50 + 30 × 综合分, 10, 95)
变动 = 今日中枢 − 上一日中枢（上一日缺失则不给变动）
```

| 出口 | 位置 | 说明 |
|---|---|---|
| 标准日报 | `reports/YYYYMMDD_量化交易日报.md` | 市场全景 + 数据体检 + 五维 + 策略 + 风险 + 数据源 |

## 九、异常兜底

| 场景 | 行为 |
|---|---|
| 主数据源失效 | 自动切备用源（行情：东财 → 腾讯；大类资产：候选代码逐个试）；连续失败标「数据暂缺」，保留其余模块 |
| 单个采集 job 抛异常 | `collect()` 内部隔离，只影响该字段，其余字段照常进报告（采集明细里逐字段写明 error） |
| 指标计算异常 | 取前值填充并标「数据异常，待复核」；无前值则留空 |
| 非交易日触发 | 自动跳过，输出「今日非交易日，无日报」（退出码 3） |
| 异常记录 | 所有异常写入报告 data_quality 与日志，便于排查 |

## 十一、已知边界

- **示例数据包不是行情。** 页面静态快照与 `--demo` 走 `demo_bundle()`，数值为示例场景，仅用于模板预览与回归测试；真实运行只认当日接口数据。
- **北向资金判不了。** 自 2024-08 起停止实时披露，`funds.north` 建议传 `null`；日报写「不适用」并说明改用主力资金与两融观察，风险规则里的北向阈值不参与判定。
- **估值分位需要序列。** `pe_pct` / `pb_pct` 这类已算好的分位优先；没有估值序列时，报告给的是**价格分位**并明确标「价格代理」，与实际 PE 分位区分开，绝不写成「估值分位 xx%」。
- **采集层能自己填多少。** 有网环境下 `live_bundle()` 可自填：指数行情、成交额、涨跌家数、涨跌停池、行业板块、主题强度、两融、龙虎榜、10Y 国债 / 商品 / 黄金 / 汇率、资产收益序列（→ 风险平价）。仍需 Agent 工具：财报 / 业绩预告、一致预期、指增超额、基差、个股截面因子、舆情样本。这些字段缺位时完整度会停在 80% 左右，且「采集明细」表逐条写明缺口。
- **风险平价不加杠杆。** 组合波动低于目标时，缩放系数上限 1.0，余额记现金并在报告里写明；单资产权重上限 40%，避免债券把权重吃满。
- **不构成投资建议。** 所有信号是规则引擎按当日数据的机械输出，仓位与止损位是纪律值，不是预测。

数据仅供参考，不构成投资建议。
